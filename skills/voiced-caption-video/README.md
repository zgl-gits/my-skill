# voiced-caption-video

Create complete short videos or animation videos with planned visuals, Mandarin voiceover, burned-in Chinese captions, and MP4 validation.

## 用途

这个 skill 适合用于：

- 制作宣传片、教育视频、动画短片、图片视频或纪实剪影。
- 把正式材料改写成适合配音的短句。
- 使用 HTML/HyperFrames、图片、SVG、TTS 和 ffmpeg 组合完成可验证成片。
- 避免只交付脚本或概念，而没有最终 MP4。

## 核心能力

- 先做 storyboard，再做画面、配音、字幕和渲染。
- 支持照片纪实、HTML 动画、AI 视频和混合制作路线。
- 强制检查黑屏、空白时段、音视频流、字幕可读性和关键帧画面。
- 附带项目脚手架与 SVG 候选下载 helper。

## 安全注意事项

- 不要提交本机绝对路径、私有素材、未发布照片、账号信息、cookie、token 或 API key。
- 如果图标网站、TTS 服务或视频工具需要登录态，把凭据放在本机环境变量或交互式登录中，不要写进 skill。
- 用户提供的真实照片应只用于用户明确要求的视频，不要用生成素材伪造真实现场。
